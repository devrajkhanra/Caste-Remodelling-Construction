# Caste Remodeling Construction — Website

Single-page marketing site for Caste Remodeling Construction (Houston, TX).

## Structure
- `index.html` — the full site (HTML/CSS/JS, no build step needed)
- `assets/` — real project photos used in the "Our Work" gallery

## Before going live
1. Open `index.html` and confirm the contact form's `action` email
   (currently `ing.arturocastellanos@gmail.com`) is correct.
2. Submit the form once after publishing — FormSubmit will email that
   inbox a one-time confirmation link. Click it to activate notifications.
3. Verify the "Licensed & Insured" claim and business hours before publishing.

## Deploying
This is a static site — any static host works (GitHub Pages, Netlify,
Vercel, Cloudflare Pages, or your own web server). No build step required;
just upload `index.html` and the `assets/` folder together.
